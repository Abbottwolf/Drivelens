# DriveLens

**Free disk space analyzer for Windows.** See what's filling your drives, find out what each big folder is, and free up space safely.

**[Download the latest version](https://github.com/Abbottwolf/Drivelens/releases/latest)** · [Website](https://anymotionpro.com/drivelens) · [Privacy](https://anymotionpro.com/drivelens/privacy)

- Scans whole NTFS drives in seconds
- Treemap, sunburst and list views
- Plain-language explanations of common space hogs
- Cleanups go to a 30-day Safety Net, so you can undo them
- Duplicate finder
- Your files never leave your PC

Windows 10 and 11, 64-bit.

If Windows shows "Windows protected your PC" when installing, click **More info**, then **Run anyway**.

This repository hosts DriveLens releases and its update feed.
